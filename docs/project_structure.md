# Project structure

lance-csr is a Cargo workspace with Python and Node.js bindings. The Rust crates are named `lance-csr*`; only the
engine crate, `lance-csr`, is published on crates.io.

```
.
├── Cargo.toml                    # Workspace: lance-csr, lance-csr-benches
├── crates/
│   ├── lance-csr/                # The engine: Cypher parser, semantic analysis, logical planner,
│   │                             # DataFusion planner, CSR index and traversal operators
│   ├── lance-csr-python/         # PyO3 bindings (built by maturin; outside the workspace)
│   ├── lance-csr-node/           # napi-rs bindings (built by napi; outside the workspace)
│   └── lance-csr-benches/        # Criterion benchmarks (not published)
├── python/
│   ├── pyproject.toml            # The lance-csr package, built with maturin
│   ├── python/lance_csr/         # Python package that wraps the bindings
│   ├── python/tests/             # Python tests
│   └── benchmarks/               # Engine micro-benchmarks (see Benchmarks)
├── nodejs/
│   ├── package.json              # The lance-csr npm package
│   ├── src/                      # TypeScript classes that wrap the bindings
│   ├── native.js, native.d.ts    # The bindings' loader and types, generated by napi
│   ├── npm/                      # One package per platform, holding its native binary
│   ├── test/                     # Node.js tests
│   ├── examples/                 # TypeScript examples the docs include
│   └── typedoc/                  # Generates the TypeScript API reference (api.md) with TypeDoc
├── examples/                     # Runnable Python examples
├── ci/check_wheel.py             # Checks a built wheel in a clean environment, without Rust
├── ci/check_npm_package.mjs      # Checks the packed npm packages the same way
└── docs/                         # Documentation
```

For how a query flows through `crates/lance-csr/src/` from Cypher text to Arrow batches, see
[How it works](execution.md) and the full source map in [DataFusion internals](internals/index.md#source-map).
