# TypeScript API reference

Everything below is exported from the `lance-csr` npm package. The classes are thin TypeScript wrappers around
the Rust engine, and this page is generated from their TSDoc comments and types, so it matches the package.
[Using from TypeScript](typescript.md) has worked examples and a table that maps each Python class and method to
its TypeScript counterpart.

| Export | Purpose |
| --- | --- |
| [`GraphConfig`](#graphconfig), [`GraphConfigBuilder`](#graphconfigbuilder-1) | Map tables to node labels and relationship types |
| [`CypherEngine`](#cypherengine) | Run many Cypher queries over registered datasets |
| [`CypherQuery`](#cypherquery) | Run one Cypher query |
| [`GraphExport`](#graphexport) | The graph as dense CSR arrays, for graph algorithms and renderers |
| [`RecordBatchStream`](#recordbatchstream) | Read a result one batch at a time |
| [`SqlEngine`](#sqlengine), [`SqlQuery`](#sqlquery) | Run SQL through DataFusion |
| [`VectorSearch`](#vectorsearch), [`DistanceMetric`](#distancemetric) | Vector similarity search and reranking |
| [`DirNamespace`](#dirnamespace) | Resolve table names to Lance datasets in a directory |
| [`LanceCsrError`](#lancecsrerror) | The error the engine throws, with a `code` |
| [`ExecutionStrategy`](#executionstrategy), [`SqlDialect`](#sqldialect) | Enums |

`version` is the package version. Datasets are apache-arrow `Table`s and `RecordBatch`es, or Lance datasets given
as [`LanceDataset`](#lancedataset) objects, and results are apache-arrow tables.

This page covers the TypeScript API. Python users should read the [Python API reference](api-reference.md), and
Rust users the [Rust API reference on docs.rs](https://docs.rs/lance-csr).
