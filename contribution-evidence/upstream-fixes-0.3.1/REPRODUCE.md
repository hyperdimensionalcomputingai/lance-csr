## Debug correctness gates

Use a clean checkout of each head. The measured environment was macOS arm64, Rust/Cargo 1.96.0, protoc and a C/C++ toolchain, uv, and Python 3.13.17. Keep the locked dependencies. Never use pip.

```bash
cargo fmt --all --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cd python
make install PYTHON=3.13.17
make test
make lint
uv run --no-sync python ../docs/check_snippets.py
cd ..
uv run --project docs --locked zensical build --strict
uvx typos@1.26.0 .
```

Run these debug gates for **all** proposed PRs before starting final production builds. `make install` builds a debug extension. The binding crate is excluded from the Rust workspace, so rebuilding the extension and running the Python suite are required as well as workspace checks.

The focused files are `test_aggregate_predicates.py` (124 cases), `test_column_casing.py` (130), and `test_query_semicolon.py` (36), under `python/python/tests/`. They use deterministic Arrow tables and real temporary Lance datasets. To demonstrate failing-before behavior, execute the same candidate regression files against an installed baseline extension outside its source package, with pytest source insertion disabled (`-o pythonpath= --import-mode=importlib`). The recorded 0.3.1 debug baseline has 166 failures and 124 passes across 290 cases: aggregate 30 failures/94 passes, casing 104/26, semicolon 32/4.

## Final production verification

Only after all debug gates pass, build baseline and candidate wheels with one fixed interpreter version and isolated targets. Rebuild each checkout's three local crates (`lance-csr`, `lance-csr-catalog`, `lance-csr-python`) rather than trusting an existing extension.

```bash
cd python
uv run --no-sync maturin build --release --locked \
  --interpreter .venv/bin/python --out dist
```

Build before importing the source package, to avoid packaging generated bytecode. The release receipts capture each source path, source/wheel/native digest, locks, compiler, actual build interpreter and PyO3 configuration. `cp312-abi3` describes the minimum ABI; the build and consumer interpreter here was Python 3.13.17.

For each wheel, copy `python/pyproject.toml`, `python/uv.lock` and the complete `python/python/tests/` directory into a fresh directory outside the checkout (rename the copied tests directory to `tests`). Copy the recorded `verify.py` there, then run:

```bash
uv sync --locked --no-install-project --python 3.13.17
uv run --no-sync --with /absolute/path/candidate.whl \
  python -I verify.py /absolute/path/candidate.whl
```

The verifier asserts an installed package location, compares archive and installed payloads, rejects packaged bytecode, and runs all copied tests. The recorded consumer PATH excluded Rust. Use default pytest import mode for the full suite because existing tests import sibling test modules.
