## Problem and change

Queries over fields such as `isMarried` can fail with a missing lowercase-column error, including queries that do not select that property, because scans project the complete schema.

Bind physical fields with exact Arrow schema names, then apply existing normalized Cypher aliases. Resolve inline filters against the schema spelling through one shared helper, including source nodes, target nodes, relationships and reversed undirected edges.

Refs https://github.com/lance-format/lance-graph/issues/105. This is a lance-csr fix; it does not close the upstream issue.
