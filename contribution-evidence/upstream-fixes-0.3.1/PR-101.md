## Problem and change

A complete valid query ending in `;` is rejected as unexpected trailing input.

Consume one optional terminator at the shared parser entry point. String literals still parse normally; repeated terminators, empty statements and appended statements remain errors.

Refs https://github.com/lance-format/lance-graph/issues/101. This is a lance-csr fix; it does not close the upstream issue.

- All three candidate debug gates passed before any final production build. Fresh locked consumers outside the checkouts verified wheel/package payloads and native hashes, then ran each complete suite with Rust absent from PATH.

Standalone scalar/null RETURN, UNION ALL, MATCH/WITH, aggregation, pagination, surrounding whitespace, semicolons in strings, collected/streaming execution, equivalent ASTs and multi-statement rejection.

## User impact

Calls accept one optional trailing semicolon. The Cypher guide documents the one-query-per-call rule. No Python signatures, stubs or dependencies change.
