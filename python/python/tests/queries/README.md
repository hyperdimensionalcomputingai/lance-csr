# Query fixtures

`ic14.cypher` is the unchanged query string from `run_query14` in
[graph-benchmark-ldbc-complex](https://github.com/hyperdimensionalcomputingai/graph-benchmark-ldbc-complex/blob/c185123edd58b37b417bc4deb2fec643fdbd5e61/neo4j/query.py).
The fixture covers collected path values, relationship endpoints, correlated pattern
comprehensions and ordered folds using a small generated graph, including parallel edges.

The source adapts the Apache-2.0 LDBC SNB Interactive reference implementation.
The upstream copyright and attribution notice is retained in `NOTICE.txt`; the
Apache-2.0 license is at the repository root. No benchmark dataset or expected
SF1 answers are distributed with this fixture.
